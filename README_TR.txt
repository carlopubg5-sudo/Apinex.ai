APInex AI Sohbet - Türkçe

Bu ZIP bir APK değil, PWA/web uygulaması paketidir. Modern mobil sohbet arayüzü, sohbet geçmişi ve API ayarları içerir.

APKBuild gibi bir serviste PWA (ZIP + manifest) seçeneğine yüklenebilir; üçüncü taraf servislerde APK oluşturulması garanti edilemez. PWA olarak yüklemek için dosyaları HTTPS destekli bir web sunucusunda yayınlayıp Android Chrome'da açın ve menüden Uygulamayı yükle / Ana ekrana ekle seçeneğini kullanın.

API ayarları: API temel adresi, API anahtarı, model ve endpoint yolu. Varsayılan endpoint /chat/completions ve OpenAI uyumlu API biçimi varsayılır. Anahtar cihazdaki tarayıcı deposunda tutulur; paylaşmayın. API sağlayıcısının CORS desteği gerekebilir.
